# Nestled (tester build)

A cozy animal logic puzzle, packaged as an installable web app. Ads and Nestled+ are switched off.

Files:
- index.html: the whole game
- manifest.webmanifest: app name, icon and full-screen settings
- sw.js: lets the game work offline and pick up updates
- icons/: home screen icons

To update the game, upload a new index.html to this repository. Phones get it the next time the app is opened with internet.
